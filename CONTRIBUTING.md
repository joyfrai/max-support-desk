# Участие в MAX Help Desk

Спасибо за интерес к проекту. Небольшие исправления можно отправлять сразу pull request'ом. Для заметных изменений сначала создайте Issue с описанием задачи и ожидаемого поведения.

## Локальная проверка

```bash
pip install -e '.[dev]'
pytest -q
python manage.py check

cd frontend
npm ci
npm run build
```

Перед отправкой pull request:

- не добавляйте `.env`, базы данных, media-файлы и реальные credentials;
- добавляйте regression test для исправленного поведения;
- обновляйте README или документацию, если изменился публичный контракт;
- запускайте `git diff --check`;
- описывайте в pull request, что изменилось и как это проверялось.

## Стиль изменений

Сохраняйте небольшие тематические commits. Не смешивайте изменение API, визуальный рефакторинг и обновление зависимостей в одном pull request без необходимости.
