# Безопасность

Пожалуйста, не публикуйте сведения об уязвимости, токены или персональные данные в открытом Issue.

Для приватного сообщения об уязвимости напишите владельцу проекта в [Telegram](https://t.me/egorprh). В сообщении укажите:

- затронутую версию или commit;
- шаги воспроизведения;
- возможное влияние;
- безопасный способ связаться с вами для уточнений.

Не отправляйте реальные credentials в чат. Перед публикацией исправления мы удалим секреты из runtime-конфигурации и проверим Git history.
